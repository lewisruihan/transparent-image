# 透明背景处理器

一个纯前端图片透明化网页工具，适合处理白底、黑色描边、内部有色块的图片。上传图片后，可以一键去除白色背景，也可以用魔棒点选黑边内部的色块，将选中的连通区域变成透明，最后导出 PNG。
网址：https://lewisruihan.github.io/transparent-image/

## 功能

- 上传本地图片
- 一键去除外侧白色背景
- 使用魔棒点选色块并转为透明
- 支持调整色差容忍度
- 支持边缘扩展
- 支持橡皮擦手动微调透明区域
- 支持恢复笔刷、撤销、重置
- 支持导出透明背景 PNG

## 本地使用

直接用浏览器打开 `index.html` 即可使用。

不需要安装依赖，也不需要启动服务器。

## 使用方法

1. 点击“选择图片”，上传一张图片。
2. 如果图片是白色背景，点击“去白底”。
3. 选择“魔棒”工具。
4. 点击黑边内部想要去除的色块。
5. 根据效果调整“色差容忍度”。
6. 如果需要手动修边，选择“橡皮”工具擦除。
7. 如果擦错了，可以使用“恢复”工具或点击“撤销”。
8. 处理完成后点击“下载 PNG”。

## 参数说明

### 色差容忍度

控制魔棒选中颜色的宽松程度。

- 数值越小，选中的颜色越接近点击处的颜色。
- 数值越大，选中的颜色范围越广。
- 黑边清晰、色块单纯的图片，通常可以从 `20` 到 `35` 开始尝试。

### 边缘扩展

控制透明区域向外扩展的像素数量。

- 默认值是 `0`，更适合保留黑色描边。
- 如果色块边缘残留明显，可以适当调到 `1` 或 `2`。
- 如果黑边被吃掉，请调回 `0`。

### 只去除相连区域

开启后，魔棒只会去除和点击位置连在一起的区域。

这适合处理被黑边包住的一块块色块，可以避免相同颜色的其他区域被一起删除。

## 部署到 GitHub Pages

1. 新建一个 GitHub 仓库。
2. 将 `index.html`、`styles.css`、`script.js` 和 `README.md` 上传到仓库根目录。
3. 进入仓库的 `Settings`。
4. 找到 `Pages`。
5. `Source` 选择 `Deploy from a branch`。
6. 分支选择 `main`，目录选择 `/root`。
7. 保存后等待 GitHub Pages 生成访问链接。

## 注意事项

- 导出格式是 PNG，因为 PNG 支持透明背景。
- 图片处理全部在浏览器本地完成，不会上传到服务器。
- 如果魔棒没有明显效果，可以提高“色差容忍度”。
- 如果黑边被误删，可以降低“色差容忍度”或关闭“边缘扩展”。

## 适合的图片类型

- 白色背景
- 主体有清晰黑色描边
- 色块之间有明显边界
- 需要保留描边，只去除背景或内部色块
